# MonsterCo - Website Multiservicios

Sitio web profesional para MonsterCo, empresa de servicios de mantenimiento y plomería en Ciudad de México y Querétaro.

## 🌟 Características

### Servicios Ofrecidos
- 🚰 **Limpieza de Tinacos y Cisternas** - Servicio profesional de limpieza y desinfección
- 🎨 **Pintura Interior y Exterior** - Acabados profesionales con materiales de calidad
- ☔ **Impermeabilización** - Protección contra filtraciones con garantía
- 🔧 **Plomería General** - Instalación, reparación y mantenimiento
- 🚨 **Emergencias 24/7** - Atención inmediata para urgencias

### Zonas de Cobertura
- **Ciudad de México (CDMX)** - Todas las alcaldías
- **Querétaro** - Zona metropolitana completa

## 🌐 Cómo Usar

### Para desarrollo local:

```bash
# Clonar el repositorio
git clone https://github.com/adairmx/monsterco.git
cd monsterco

# Iniciar servidor local (Python)
python3 -m http.server 8000

# O usar cualquier otro servidor web
# Abrir en navegador: http://localhost:8000
```

### Para producción:

1. Subir todos los archivos a tu servidor web
2. Actualizar las URLs en `sitemap.xml` con tu dominio real
3. Actualizar los datos de contacto en todas las páginas
4. Configurar certificado SSL (HTTPS) para mejor SEO
